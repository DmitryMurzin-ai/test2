# Обучение

Интерактивная программа с обучающими материалами для сотрудников. Новички проходят в ней адаптацию, а опытные сотрудники освежают знания и изучают обновления. Материалы разбиты на курсы и уроки, после уроков идут тесты, а прогресс каждого сотрудника сохраняется.

> **Статус:** проект в начальной стадии, описанная ниже структура — план.

## Возможности

- Каталог курсов: отдельные треки для новых сотрудников (адаптация) и для опытных (повышение квалификации, обновления регламентов)
- Уроки с текстом, изображениями и видео
- Тесты после уроков с мгновенной проверкой и пояснениями к ответам
- Сохранение прогресса и результатов тестов для каждого сотрудника
- Материалы хранятся в простых текстовых файлах (Markdown и YAML), поэтому их можно добавлять без программирования

## Стек

- **Python 3.11+**
- **[Streamlit](https://streamlit.io/)**: веб-интерфейс, который открывается в браузере
- **PyYAML**: чтение описаний курсов и тестов
- **SQLite**: хранение прогресса сотрудников (встроен в Python)

## Установка

Нужен установленный Python 3.11 или новее.

```bash
git clone https://github.com/DmitryMurzin-ai/test2.git
cd test2

python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate

pip install -r requirements.txt
```

## Запуск

```bash
streamlit run app.py
```

Программа откроется в браузере по адресу http://localhost:8501.

## Как добавить материалы

1. Создайте папку курса в `content/` и файл `course.yaml`:

   ```yaml
   title: Адаптация новых сотрудников
   description: Знакомство с компанией, правилами и инструментами
   lessons:
     - 01-intro
   ```

2. Добавьте урок в формате Markdown, например `01-intro.md`.
3. При необходимости добавьте тест `01-quiz.yaml`:

   ```yaml
   questions:
     - question: Кому сообщать о проблеме с доступами?
       options:
         - Руководителю
         - В службу поддержки
         - Коллеге
       answer: 1
       explanation: Все запросы по доступам обрабатывает служба поддержки.
   ```

4. Перезапустите программу, и новый курс появится в каталоге.
